## This Portfolio

Built with **React 18 + Vite** — zero UI framework, pure CSS glassmorphism, canvas particle animation, and scroll-reveal via Intersection Observer.

### Run locally

```bash
git clone https://github.com/yousef-alkhrissat/portfolio
cd portfolio
npm install
npm run dev        # → http://localhost:5173
```

```bash
npm run build      # production build → dist/
npm run preview    # preview the production build
```

### Structure

```
src/
├── components/
│   ├── Navbar.jsx       scroll-aware nav + mobile menu
│   ├── Hero.jsx         canvas particle mesh + typing animation
│   ├── About.jsx        bio + stat cards
│   ├── Skills.jsx       grouped devicons + skill badges
│   ├── Experience.jsx   alternating timeline + see-more toggle
│   ├── Projects.jsx     company-filtered project grid
│   ├── Education.jsx
│   ├── Contact.jsx      contact form with success state
│   ├── Footer.jsx
│   └── BackToTop.jsx
├── App.jsx              global Intersection Observer setup
└── index.css            ~700 lines — no CSS framework
```
